# 할 일 관리 웹앱

작은 할 일(TODO) 관리 웹앱을 기능 단위로 조금씩 만들어 가는 프로젝트입니다.

- 진행 상황: [프로젝트 보드](https://github.com/orgs/jhlim2-forks/projects/3)
- 개발 근거 문서와 문서 규칙: [docs/README.md](docs/README.md)

## 일하는 방식

요청은 이슈로 남깁니다. 이슈를 보드의 `접수 대기` 컬럼에 올리면 팀이 요청을 근거 문서와 대조하고, 필요하면 문서 PR을 먼저 연 뒤 구현 PR을 엽니다.

- 리더가 확인해야 하는 이슈와 PR에는 리더가 담당자나 리뷰어로 지정됩니다. 보드의 [리더 확인 필요](https://github.com/orgs/jhlim2-forks/projects/3/views/2) 보기에서 모아 볼 수 있습니다.
- PR의 결과 승인은 리뷰의 **Approve**, 수정 요청은 **Request changes**로 남깁니다.
- 병합과 이슈 종료 판단은 사람이 합니다. 병합 후 검증이 통과하면 이슈가 닫힙니다.

## 실행

아직 구현이 없습니다. 첫 기능이 병합되면 실행 방법을 이곳에 적습니다.
