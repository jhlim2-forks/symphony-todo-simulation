# 작은 TODO 웹앱

Symphony 오케스트레이터와 AI 역할(기획·구현·리뷰)이
"AI 기반 개발 프로세스 정의서"의 절차대로 개발하는 시뮬레이션 대상 프로젝트입니다.

- 진행 상황: [TODO 웹앱 개발 보드](https://github.com/orgs/jhlim2-forks/projects/2/views/2)
- 근거 문서와 문서 규칙: [docs/README.md](docs/README.md)

현재는 빈 화면만 제공하는 골격입니다. Go 1.26.8 이상에서 실행합니다.

```sh
go run . -listen 127.0.0.1:8091
```

http://127.0.0.1:8091 에서 확인합니다.
