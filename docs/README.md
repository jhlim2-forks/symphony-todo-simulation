# 근거 문서

이 디렉터리의 문서는 사람이 승인하여 기본 브랜치에 병합한 버전만 개발 근거로 사용합니다.

| 문서 | 내용 | 상태 |
| --- | --- | --- |
| `requirements.md` | 제품 요구사항, 사용자 시나리오, API 계약 | 아직 없음 |
| `design.md` | 구조, API·UI 설계, 수용 기준, 위험 | 아직 없음 |

## 문서 규칙

문서 검증 게이트가 아래 규칙을 기계적으로 검사합니다.

- `requirements.md`에는 `## 배경`, `## 요구사항`, `## API 계약`, `## 범위 밖` 절이 있어야 합니다.
- 요구사항은 `## 요구사항` 절에 `- **REQ-01** 내용` 형식으로 정의하며 ID는 중복되지 않습니다.
- `## API 계약`은 필수 API 검사 대상인 `GET /api/todos`, `POST /api/todos`, `PATCH /api/todos/{id}`, `DELETE /api/todos/{id}`를 모두 명시합니다.
- `design.md`에는 `## 구조`, `## API`, `## UI`, `## 수용 기준`, `## 위험` 절이 있어야 합니다.
- 모든 요구사항 ID는 `## 수용 기준`에서 한 번 이상 참조되어야 하며, 정의되지 않은 ID를 참조하지 않습니다.

## 프로젝트 제약

- Go 표준 라이브러리와 HTML/CSS/JavaScript만 사용합니다. 외부 패키지·CDN을 추가하지 않습니다.
- `main.go`의 `-listen` 플래그와 `NewHandler() http.Handler` 시그니처를 유지합니다.
- 구현은 `app.go`와 `index.html`에 둡니다.
